DoH와 DoT, 무엇이 다른가요?+

둘 다 기기와 DNS 서버 사이의 조회를 암호화해요. DoH는 HTTPS를 사용하고, DoT는 DNS를 위한 TLS 연결을 사용합니다. 기기가 지원하는 방식으로 설정하면 돼요.

암호화를 사용해도 선택한 DNS 제공자는 조회를 처리할 수 있어요. 웹사이트 접속을 익명으로 만들거나 VPN을 대신하는 기능은 아닙니다.

암호화 DNS 공식 설명 읽기
이 사이트가 지금의 DNS 상태를 검사하나요?+

이 사이트는 설정을 돕는 안내서예요. 브라우저가 제공하는 OS 정보로 첫 안내를 선택하며, 감지가 맞지 않으면 다른 OS를 직접 고를 수 있어요.

방문만으로 현재 DoH·DoT 사용 여부를 확인할 수는 없어요. 설정 후에는 각 안내의 확인 방법을 따라주세요. 브라우저에만 설정했다면 다른 앱에는 적용되지 않을 수 있습니다.

설정 후 인터넷 연결이 안 되면 어떻게 하나요?+

선택한 안내의 ‘원래 설정으로 돌아가기’를 먼저 따라주세요. 공용 Wi-Fi 로그인, VPN, 회사·학교의 관리 설정 때문에 암호화 DNS 연결이 제한될 수 있어요.

관리 중인 기기는 해당 네트워크의 안내를 먼저 확인해주세요. 설정 화면의 이름은 OS 버전이나 기기 제조사에 따라 조금씩 달라질 수 있습니다.

작은 설정 하나로, DNS 조회도 조금 더 비공개로.
