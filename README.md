DNS(Domain Name Service)란, 우리가 인터넷에서 웹사이트에 접속할 때 그 웹사이트 이름을 넣으면 시스템에서 도메인 이름에 대응하는 ip주소를 알려줌으로써 인터넷을 사용하는 사람들이 자연스럽게 ip주소를 안 외워도 특정 ip로 접근할 수 있는 기능이다.

DNS는 인터넷의 핵심 구성요소이지만 http가 https환경으로 강제된 것과 다르게 DNS는 암호화 없이 평문으로 오간다. 따라서 현대 인터넷 환경에서 특정 통신장비가 인터넷을 사용하는걸 감청하는 관점에서(**감청은 당연히 불법이다. 따라하지마세요 저도 민간인 감청은 단 1번도 안 해봤습니다. 절대 하지마세요.**) 보면 일반적인 인터넷 패킷은 전부 다 https라서 암호화된 와중에 DNS만 덩그러니 암호화되지 않은 상태로 나올 것이다. 그러면 이 패킷정보를 기반으로 '이 사람이 이 사이트를 언제 들어갔고..' 식의 정보들은 엄청 쉽게 모을 수 있게 되는 것이다!

따라서 기술적으로 이 DNS를 암호화하는 것은 정말정말정말정말정말 중요하다. 최상단 웹사이트 들어가면 5개 운영체제에서 6개 국어로 하는 방법을 GPT한테 써달라 했으니 그걸 적극적으로 따라해줬으면 좋겠다. 

'DNS 서버'를 어쨋든 연결은 해야하는데, 필자는 구글 또는 클라우드플레어에 연결하는 것을 추천한다. 이미 전세계에서 가장 많은 점유율을 들고 있고 따라서 뭔가 문제생기면 그땐 나 혼자만의 문제가 아닐테니까 무조건 구글/클라우드플레어 dns서버에 연결하는 것을 추천한다. 이 서버쪽에선 당연히 특정 ip주소의 누군가가 어디를 언제 접속하려고 하는지 이런것들 다 볼 수 있지만 그 서버를 운영하는 대기업이 '저희는 로그를 남기지 않습니다'라고 주장하면 일단 믿어야지..
